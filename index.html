    How this works. Every service is probed straight from your browser with a fetch(…, { mode: "no-cors" }) request (an image probe is used as a fallback if fetch is unavailable). Browser CORS rules hide the HTTP status code, so “UP” only means the host answered at the network level — it does not prove the service itself is healthy. Each probe is capped at ~6 seconds; a host that is unreachable, blocked, or offline is reported as DOWN. The list is checked automatically every 30 seconds.
